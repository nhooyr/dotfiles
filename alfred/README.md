# Alfred 6

This only contains my Alfred 6 theme.

I would share the rest of my Alfred preferences but they contain sensitive information like API keys and
personal data.

The main features I benefit from are:

1. Vastly faster performance than Spotlight.
2. Clipboard management.
3. Spotify integration with [alfred-spotify-mini-player](https://github.com/vdesabou/alfred-spotify-mini-player)
4. Dictionary.app integration.
4. Terminal.app integration.
5. Advanced calculator syntax with GCMathParser.
6. Lots of neat little features. Apple should buy out Alfred and replace Spotlight. It's that good.
