# Alfred

[Alfred 6](https://alfred.app) is far superior to Spotlight.

1. Light speed responsiveness.
2. Clipboard and snippets management.
3. Spotify integration with [nhooyr/Spotify.alfredworkflow](https://github.com/nhooyr/Spotify.alfredworkflow).
4. Dictionary.app integration.
4. Terminal.app integration.
5. Advanced calculator syntax with GCMathParser.
6. https://alfred.app/workflows/alfredapp/
   - I have 38 of these installed.
7. Numerous polished details and thoughtful touches.

Apple should buy out Alfred and blanket replace Spotlight. It's that good.
