# Terminal palette

`0nhooyr.terminal` explicitly sets all 16 ANSI colors to standard sRGB values.
The profile stores compact archived color objects; this table records their
six-digit hex values.

| Color | Regular | Bright |
|---|---|---|
| Black | `#000000` | `#5C5C5C` |
| Red | `#B60000` | `#B60000` |
| Green | `#0A5C07` | `#0A5C07` |
| Yellow | `#FFFF00` | `#FFFF00` |
| Blue | `#0000B3` | `#0000B3` |
| Magenta | `#6E066E` | `#6E066E` |
| Cyan | `#0A4045` | `#0A4045` |
| White | `#FFFFFF` | `#FFFFFF` |

Regular and bright yellow are reserved for match highlighting and autocomplete
selection, always as a background with black text.
